문서 1건의 구조 개요(필요하면 페이지 이미지)와 **개념 질문 목록**을 준다. 각 질문에 답하라.

## 규칙
1. `value`: `yes`(있다) / `no`(없다) / `na`(이 문서 종류에는 해당 없음). **애매하면 `no` 로 한다.**
2. `yes` 일 때는 `page`(페이지 번호)와 `evidence_quote`(문서에서 그대로 옮긴 한 줄)를 반드시 넣는다.
   근거를 못 찾으면 `no` 다.
3. 표현이 달라도 **같은 기능**을 하면 `yes` 로 한다.
   질문의 인용 문구와 글자가 정확히 같을 필요는 없다. 같은 역할을 하는 항목이면 인정한다.
   (예: 질문이 "A 표"를 묻는데 문서에는 제목 없이 같은 열 구성의 표가 있으면 yes)
4. 내용의 질이나 타당성은 판단하지 않는다. 있고 없음만 본다.
5. 질문 목록에 있는 모든 `id` 에 대해 답을 하나씩 돌려준다. 빠뜨리거나 추가하지 않는다.
